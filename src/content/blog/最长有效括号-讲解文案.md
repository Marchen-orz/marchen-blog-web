# 最长有效括号 - 完整讲解文案

---

## 题目描述

给你一个只包含 `(` 和 `)` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

**什么是有效括号？** 左右括号匹配，即每个左括号都有对应的右括号将其闭合。比如 `"(()())"` 是有效的。

---

## 示例

**示例 1：**
```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

**示例 2：**
```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

**示例 3：**
```
输入：s = ""
输出：0
```

## 2. 引导审题

好的，咱们现在一块儿读题目哈~

用红笔标注一下关键信息：

- 只包含 `(` 和 `)` 这**两种字符**
- 要找的是**子串**，不是子序列
  - 子串必须是**连续**的
  - 比如从 "abcde" 中，"bcd" 是子串，但 "ace" 不是
- 需要返回**长度**，不是子串本身
- 有效是指：每个 `(` 都有对应的 `)` 把它闭合

## 3. 考点知识点讲解与解题关键分析

### 知识点板书（屏幕右上方，红色笔）

```
栈
- 后进先出 (LIFO)
- 专门处理匹配问题
- 遇到左括号入栈，遇到右括号出栈
```

### 口播讲解

这道题要我们找最长的有效括号子串。看到括号匹配，大家应该想到什么数据结构呀？没错，就是**栈**。

栈的特点是**后进先出**，非常适合处理这种"匹配"问题。就像我们平时洗盘子，最后放上去的盘子最先被拿走。

那具体怎么做呢？

我们用栈来存左括号 `(`，用两个变量来记录长度：
- `current_len`：当前连续有效的括号长度
- `max_len`：记录过程中出现的最大长度

---

## 4. 步骤剖析

### 解题思路

**核心思想：** 用栈来匹配括号，同时用一个变量记录当前有效长度。

```
遇到 '(' → 入栈，等待匹配
遇到 ')' → 出栈，表示匹配成功，长度 +2
```

但是要注意，什么时候应该重置长度呢？

- 如果出栈后**栈空了**，说明一段完整匹配结束了，更新最大长度，重置当前长度
- 如果栈**本身就是空的**，说明这个 `)` 没法匹配，直接重置当前长度为 0

---

### 示例演示：s = ")()())"

手写表格演示，边写边讲：

| 步骤 | 索引 | 字符 | 操作 | 栈状态 | current_len | max_len |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 初始 | - | - | 初始化 | `空` | 0 | 0 |
| 1 | 0 | `)` | 栈空，无法匹配 | `空` | **重置=0** | 0 |
| 2 | 1 | `(` | 入栈 | `(` | 0 | 0 |
| 3 | 2 | `)` | 出栈匹配 | `空` | **+2=2** | **2** |
| 4 | 3 | `(` | 入栈 | `(` | 2 | 2 |
| 5 | 4 | `)` | 出栈匹配 | `空` | **2+2=4** | **4** |
| 6 | 5 | `)` | 栈空，无法匹配 | `空` | **重置=0** | 4 |

问：第3步和第5步，出栈后栈空了，为什么还要继续？

答：因为后面可能还有新的有效括号呀！比如第3步结束后，第4步又来了一个 `(`，说明新一轮开始了。

---

### 再用一个例子演示：s = "(()()"

这个例子有**嵌套**的情况。

| 步骤 | 索引 | 字符 | 操作 | 栈状态 | current_len | max_len |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 初始 | - | - | 初始化 | `空` | 0 | 0 |
| 1 | 0 | `(` | 入栈 | `(` | 0 | 0 |
| 2 | 1 | `(` | 入栈 | `((` | 0 | 0 |
| 3 | 2 | `)` | 出栈匹配 | `(` | **+2=2** | **2** |
| 4 | 3 | `(` | 入栈 | `((` | 2 | 2 |
| 5 | 4 | `)` | 出栈匹配 | `(` | **2+2=4** | **4** |

扫完了，最大长度是 **4**。

问：为什么第5步栈不空，但长度还能累加？

答：因为栈里还有一个 `(` 在等待匹配，说明当前有效子串还没结束，继续累加就行。

---

### C++ 伪代码（手写板书用）

```cpp
// 初始化
stack<char> st;        // 栈，用来存左括号
int max_len = 0;       // 最大长度
int current_len = 0;   // 当前有效长度

// 遍历字符串
for (int i = 0; i < s.length(); i++) {
    if (s[i] == '(') {
        // 遇到左括号，入栈等待匹配
        st.push('(');
    } else {
        // 遇到右括号
        if (st.empty()) {
            // 栈空，说明这个 ) 无法匹配，重置
            current_len = 0;
        } else {
            // 栈不空，出栈匹配
            st.pop();
            current_len = current_len + 2;  // 匹配成功，长度+2

            // 如果栈空了，说明一段完整匹配结束
            if (st.empty()) {
                max_len = max(max_len, current_len);
                current_len = 0;  // 重置，准备下一轮
            }
        }
    }
}

return max_len;
```

---

### 代码讲解

好，现在我们来写代码。

首先定义一个栈 `st`，还有两个变量：`max_len` 记录最大长度，`current_len` 记录当前有效长度。

然后遍历字符串：
- **遇到 `(`**：入栈，等待被匹配
- **遇到 `)`**：
  - 如果栈空了，说明这个 `)` 没法匹配，把 `current_len` 重置为 0
  - 如果栈不空，出栈，`current_len` 加 2
  - 出栈后如果栈空了，说明一段完整匹配结束了，更新 `max_len`，然后重置 `current_len`

最后返回 `max_len` 就可以了。

## 5. 要点回顾

好，那么我们一起来总结一下这道题：

### 知识点回顾

1. **考察的知识点**：栈的应用
2. **栈的特点**：后进先出，适合处理匹配问题
3. **有效括号的判定**：每个 `(` 都有对应的 `)` 把它闭合

### 解题步骤总结

```
遇到 '(' → 入栈
遇到 ')' → 出栈，长度+2
          ↓
       栈空了吗？
          ↓
    是 → 更新max_len，重置current_len
    否 → 继续累加current_len
```

### 易错点提醒

大家最容易搞错的是几个地方：

1. **栈空时遇到 `)`**：不是什么都不做，而是要重置 `current_len = 0`
2. **出栈后栈空了**：这时要更新 `max_len`，并且重置 `current_len = 0`，准备下一轮
3. **出栈后栈不空**：说明有嵌套，`current_len` 继续累加，不要重置

## 附录：完整测试代码

```cpp
#include <iostream>
#include <stack>
#include <string>
#include <algorithm>

using namespace std;

class Solution {
public:
    int longestValidParentheses(string s) {
        stack<char> st;
        int max_len = 0;
        int current_len = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s[i] == '(') {
                // 遇到左括号，入栈
                st.push('(');
            } else {
                // 遇到右括号
                if (st.empty()) {
                    // 栈空，无法匹配，重置
                    current_len = 0;
                } else {
                    // 出栈匹配
                    st.pop();
                    current_len = current_len + 2;

                    // 出栈后栈空了，一段完整匹配结束
                    if (st.empty()) {
                        max_len = max(max_len, current_len);
                        current_len = 0;
                    }
                }
            }
        }

        return max_len;
    }
};

int main() {
    Solution sol;

    cout << "s = \"(()\" -> " << sol.longestValidParentheses("(()") << endl;      // 输出: 2
    cout << "s = \")()())\" -> " << sol.longestValidParentheses(")()())") << endl;  // 输出: 4
    cout << "s = \"\" -> " << sol.longestValidParentheses("") << endl;            // 输出: 0
    cout << "s = \"(()()\" -> " << sol.longestValidParentheses("(()()") << endl;   // 输出: 4

    return 0;
}
```

**运行结果：**
```
s = "(()" -> 2
s = ")()())" -> 4
s = "" -> 0
s = "(()()" -> 4
```
